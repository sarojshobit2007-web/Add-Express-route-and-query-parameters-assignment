## 📌 Project Description

This project is based on **Express.js Routing, Route Parameters, and Query Parameters**.

The project contains three assignments:

1. Route Parameters
2. Query Parameters
3. Student Profile using Route and Query Parameters

The purpose of this project is to understand how Express.js handles dynamic URLs and data passed through query strings.

---

## 🎯 Objectives

- Understand Express.js routing.
- Learn how to use `req.params`.
- Learn how to use `req.query`.
- Create dynamic routes.
- Handle query parameters.
- Run an Express.js server locally.
- Test routes using a web browser.
